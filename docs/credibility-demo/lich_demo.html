The affinity tracker

RAG + a separate LLM relationship scalar

The most sophisticated community pattern we could verify at source level (a mod for one specific game, not an engine): a separate LLM judge moves one signed number (−100…+100) by deltas, maps it to a tier (Hostile…Devoted), keeps a sticky worst-deed note.
